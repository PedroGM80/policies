# policies

Políticas de privacidad de las apps de TeckelSoft, publicadas con GitHub Pages en
https://pedrogm80.github.io/policies/

Este es el único repositorio público necesario para Google Play: cada app enlaza
a `https://pedrogm80.github.io/policies/<app>/` y su código puede seguir privado.

Para añadir una app: crea `<app>/index.md` (o `index.html`) y añádela a `index.md`.
